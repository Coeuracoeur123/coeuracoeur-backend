Authentication

POST

/api/register

🌐 Public

Register a new user account. Créer un nouveau compte utilisateur.

Request Body — application/json
FieldTypeRequiredNotes
namestringYesDisplay name
emailstringYesMust be unique
passwordstringYesStored hashed (bcrypt)
rolestringNo"user" or "admin" · Default: "user"

Response 200

{ "message": "User created" }
POST

/api/login

🌐 Public

Authenticate and receive a JWT token valid for 7 days. S'authentifier et recevoir un jeton JWT valable 7 jours.

Request Body — application/json
FieldTypeRequired
emailstringYes
passwordstringYes

Response 200

{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": { "id": 1, "name": "Alice", "role": "admin" }
}

400 — "User not found"
400 — "Wrong password"
